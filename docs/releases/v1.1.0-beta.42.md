# Core beta42 — shared chat commands, local candidate

Catalogue and semantics now live in Core for standalone and embedded hosts.
Deferred reset plans stop_runs, release_session, rotate_session. Resource release
uses the verified old session lock with a ten-second drain/release bound; failed
cleanup prevents host rotation. Old stored history is retained for retaining
hosts. Long-term memory and vault remain unchanged. See [the contract](../chat-commands.md).

This is a local release preparation, not a publication receipt. Four runtime
family wheels are version 1.1.0b42. The nineteen independently versioned packages
remain byte-for-byte public assets: eighteen from beta37 and capability-host b3
from beta40. Their complete tracked source inventories were compared without
changes. Do not rebuild or relabel them as beta42.

Installed-wheel checks and the exact candidate manifest are recorded separately
in the local shared-chat-commands-release-r2 receipt before publication review.
No provider/model or production acceptance is claimed here.

Local installed qualification passed 681 public tests and 97 subtests. The
normal standalone candidate closure resolves with 159 compatible packages;
its Core imports (327 loaded modules) all originate in isolated site-packages,
with PYTHONPATH unset. A delayed active-provider cancellation and bounded
resource-drain failure are included. Nineteen independent wheel RECORDs and
hashes are verified against their public assets. Public-byte acquisition and
real-provider/host release acceptance are still required after publication.
