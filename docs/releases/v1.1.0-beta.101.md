# Core 1.1.0 beta101

Session loop turns show up live.

- When a session loop's turn ends, the scheduler sends one content-free
  `turn_complete` frame for the conversation through the host's broadcast
  sink for detached runs, with the outcome. A client that has the
  conversation open reloads it, so the loop's answer appears without
  reopening the chat. See `docs/session-loop.md`.
