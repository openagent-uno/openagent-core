# Core beta44: discovery and optional imports

Core, SQLite, gateway and the Python SDK use `1.1.0b44`, with exact matching Core
requirements. Existing beta43 artifacts stay unchanged. Beta44 combines the
published beta43 optional-import and admitted-command contracts with
[discovery presentation v1](../discovery-presentation.md).

The synchronous SQLite store and privacy snapshot guard work without optional
engine packages. Discovery adds bounded authorized hints while preserving exact
opaque references, dispatch, revocation, schemas and pagination. Independently
versioned modules and tools retain their selected original bytes and versions.

The canonical beta version is suitable for hosts whose history policy admits
qualified releases and prereleases while rejecting unknown development forms.
Build fresh wheels from the committed upstream source; never relabel old files
or weaken a host downgrade check to adopt a development candidate.

Qualification exercises these public contracts and coupled package metadata,
then verifies freshly built wheel RECORD digests. Publication, host memory
qualification, signed downstream bundles and actual providers are separate gates.
