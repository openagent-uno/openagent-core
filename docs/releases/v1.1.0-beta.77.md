# Core beta 77

The model-facing tool gateway automatically pages long structured collections
without a native cursor. Continuations read the saved invocation after checking
the current run, session and tool binding. Existing native cursors pass through.

The shared SQLite paginator filters at the source for scheduled tasks, workflow
runs, event deliveries and skill data. It limits each page by item count and
serialized size. See [tool result pagination](../tool-catalog.md#pages-for-structured-tool-results).
