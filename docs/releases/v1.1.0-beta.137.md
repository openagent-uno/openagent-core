# Core beta137 — typed account fallback and shared custody accounting

Declared image fallback uses exact accounts, existing budget admission and actual
connection attribution. Only explicit account refusals can move to a sibling;
uncertain jobs and cancellations are never replayed. Old text-only groups retain
their policy; offline adoption derives the kinds from the existing catalog.
Local account fallback changes update linked text/image connections together.

The optional custody host shares metrics and Codex usage accounting across root
and exact-account routes, including a final lifespan flush. Model-declared
parameter schemas take precedence over generic presets, and audio string fields
reject invalid types while retaining empty values.

Qualification includes image failover and cancellation boundaries, account-local
policy isolation, root/exact usage aggregation, migration preservation and typed
model forms. Real providers and deployed hosts require separate acceptance.
