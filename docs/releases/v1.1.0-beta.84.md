# Core 1.1.0 beta84

A turn that fails or is cancelled after running tools no longer disappears
from the model's working history. The run keeps its user message and every
tool call whose results were recorded, drops an unanswered trailing call, and
closes with a fixed note that it ended without a final answer. The next turn
therefore knows which side effects already happened instead of forgetting or
repeating them. Paused runs and explicit `skip_statuses` filters are unchanged.
Six regressions cover the prefix trimming, persistence on failure and replay.
