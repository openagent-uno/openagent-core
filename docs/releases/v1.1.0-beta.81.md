# Core 1.1.0 beta81

An explicit stream stop always publishes a cancelled terminal boundary, even
when the runner task was cancelled before entering its cleanup block. Its
terminal frames are suppressed during the bounded drain, preserving one
completion per explicit stop and separating the following channel turn.
Confirmed outgoing history and the one-level delegation fence from beta80
remain unchanged. The regression queues an input and stop before the runner
starts, then proves that a fresh turn completes independently.
