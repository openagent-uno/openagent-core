# Embedding beta 165

Embedded hosts can set persistent machine and disk budgets and limit running guests, CPU and RAM through a transactional SQLite or PostgreSQL capacity store. Pool and principal counters serialize admission across workers. A host that requires a capacity provider checks its resource inventory before clone and start.

Task computers now support authorized suspension of one enrolled generation. The broker fences its lease before stopping the guest. Redelivery can complete an interrupted stop after a controller restart. Resuming the same volume issues a fresh generation. Revocation retains the disk and releases running capacity after the hypervisor confirms shutdown.

The reference provider qualified two private Linux guests on one hypervisor, each configured with one vCPU, 1 GiB RAM and 4 GiB disk. The test transferred a single active slot between two principals and verified independent files and Chromium cookies through suspension and reattachment. See the [pool and suspension contract](../remote-capabilities.md#pool-capacity-and-suspension).
