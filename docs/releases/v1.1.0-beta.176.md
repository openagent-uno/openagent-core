# Embedding beta 176

An agent using the SQLite artifact repository can return an original file
supplied by the user in the same conversation after reading an authorized
document. This works on the first turn, while the upload is recorded on the
admitted request, and on later turns through the saved user message.

Session inspection also forwards the current recipients to the host when
reading or listing sessions.

Core verifies the original file, the recipients and current access when the
agent looks up the file and again when it prepares the reply. Creating a file
from document content still requires a publisher that can enforce the source
permissions. Hosts without verifiable input provenance keep the protected
operation unavailable.
