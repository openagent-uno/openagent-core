# OpenAgent Core 1.1.0b172

Host applications can stream a desktop selected from the current session's
authorized capability catalog. Core checks the human viewer, the exact producer
and its authorization during delivery and while awaiting frames. The host owns
device assignment, the media producer and delivery transport.
[Desktop stream contract](../remote-capabilities.md)

Automation cancellation now writes the exact authorized run IDs using the
scheduler's persistence contract. The SQLite scheduler records cancellation
atomically with a definition and state check. A PostgreSQL scheduler also needs
durable definition, queue, projection and execution ownership stores.
[Automation host contract](../automation-host-contract.md)
