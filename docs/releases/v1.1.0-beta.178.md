# Embedding beta 178

In a private conversation an embedding can let a delegated agent work with the
document revisions the parent has already used. The embedding verifies the
child, its current recipients and its link to the source conversation. Core
checks the revisions again when the parent receives the result and before
publishing it. Reading another note requires the child's own permissions.

Cancelling a scheduled task or workflow while its first run is starting now
preserves that cancellation when the runtime receives the admission
acknowledgement. Recovery can distinguish a discarded start from work that
was admitted.
