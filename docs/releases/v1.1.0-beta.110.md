# Core 1.1.0 beta110

The prompt explains computers and browsers.

- New framework rule `core.computers` (tools section, selected by
  tool-discovery): on each target the agent picks the narrowest kind of tool
  (shell, files and editor; its own browser; screen control of the person's
  desktop and signed-in browser), reads pages as text before screenshots,
  checks every change before the next step, never types secrets or solves a
  CAPTCHA, and stops before an irreversible or public action unless asked.
  Before reporting that something cannot be done it checks the other targets
  in `<capabilities>`: a read-only source is not the only way to act. A live
  run had declared itself blocked although a connected device could do the
  job.
- The tools section budget is 4,800 characters (was 3,200).
- Modules: tool-discovery 1.1.0b3; openagent-modules(-full) 1.1.0b6;
  reference host example 1.1.0b4.
