# Embedding beta 169

SQLite hosts can accept turns while historical search data is repaired in bounded batches. The repair cursor survives restart. Scheduler claims, interrupted work and terminal receipts now retain their durable identities across writer contention. [SQLite concurrency](../sqlite-commit-concurrency.md) and [memory access](../memory-access.md).

A configured MCP source can recover after a transient startup or reconnect failure. Hosts can authorize outage visibility for a specific source and audience. A tool removed and reintroduced on the same connection receives a new reference. Reconnection never automatically repeats a tool operation already sent. [Transport recovery](../mcp-transport-recovery.md) and [remote capabilities](../remote-capabilities.md).

The synchronized Python Core, SQLite, PostgreSQL, gateway and SDK wheels use `1.1.0b169`. The JavaScript SDK remains at `1.0.0-beta.4`. The release updates the embedding artifacts. Standalone hosts adopt them through their own versioned composition.
