# Core 1.1.0 beta86

The vault no longer stops versioning silently. An abandoned `.git/index.lock`
(left by a Git process that died) made every later `git add` fail, and each
failure was treated as "nothing to commit"; one installation kept four months of
edits uncommitted. A lock older than ten minutes is now removed and the commit
retried, and any Git failure is logged as a warning. `vault_validate_note`
synchronises its index once before reporting a link to a just-written note as
broken. Beta85's transient zero-output stream retry is included. See
`docs/vault-history.md`.
