# Core beta144: storage bootstrap contention and cleanup

Ready databases no longer reinstall their legacy journal triggers or rescan
historical automation rows during every connection. Missing triggers retain
the normal locked repair and seed path. A failed or cancelled database bootstrap
closes its owned connection, rolling back unfinished writes and releasing the
SQLite worker. Regression cases cover an active concurrent writer, missing
trigger repair, migration failure and cancellation.

Wheel qualification explicitly disables development source paths when running
the public suite, so the suite imports the installed candidate cohort.
