# OpenAgent Core 1.1.0 beta 174

Long transcript pages can associate visible assistant text with the tools it
preceded. The layout uses the stored run journal and only splits a response
when the visible deltas attest its exact text. Canonical message identity and
the complete response stay available to callers. See [Session history](../session-history.md).

Provider streams with no incoming events have a bounded idle wait. Existing
fallback and cancellation policies still govern how an idle stream ends.
See [Usage](../USAGE.md).

Verified files returned from tools are published through the host attachment
contract and represented by the authorized session attachment. The model
transcript receives the file reference without embedding the file bytes.
See [Usage](../USAGE.md).

The package set contains the matching Core, Python SDK, HTTP gateway and
SQLite and PostgreSQL adapters. The release manifest records source and
artifact digests.
