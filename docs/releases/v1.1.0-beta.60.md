# OpenAgent Core beta60

The public `ComputerInteraction` service lets a host discover a source's
desktop control tools and call an exact tool reference for capture or input.
The host supplies the authenticated human actor, session, agent and allowed
source. Core checks session permissions, source ownership and tool visibility,
including after the call. See the
[remote capability contract](../remote-capabilities.md).

Core, SQLite, gateway and Python SDK advance together to `1.1.0b60`.
Independently versioned module wheels retain their versions.

The [release](https://github.com/openagent-uno/openagent-core/releases/tag/v1.1.0-beta.60)
includes source and wheel digests and installed-engine qualification.
