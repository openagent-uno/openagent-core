# OpenAgent Core beta59

The FFmpeg video preview extractor accepts an optional `frame_edge` from 2 to
768 pixels. The default longest edge is 384 pixels. Hosts can configure a
separate extractor for [staged operation completions](../staged-operations.md)
to provide more visual detail and a different sampling cadence. Input size,
JPEG size, sample count and decode time retain their existing bounds.

Core, SQLite, gateway and Python SDK advance together to `1.1.0b59`.
Independently versioned module wheels retain their versions.

The [release](https://github.com/openagent-uno/openagent-core/releases/tag/v1.1.0-beta.59)
includes source and wheel digests, installed-engine qualification and test
reports. Focused tests verify real frame dimensions and the independent
operation binding with its fallback.
