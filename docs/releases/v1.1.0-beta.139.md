# Core beta139 — independent subscription-host installation

The optional subscription HTTP host can construct Claude and Codex services with
only the declared `subscription-host` extras. Importing a protocol's connection
identity helper previously initialized the model package's reasoning providers
and required undeclared engine dependencies. Those implementations now load
only when their existing public class exports are requested.

Model contracts, aliases, credential paths, account identities, HTTP authorization
and inference behavior stay unchanged. The regression constructs and closes both
subscription services and HTTP apps while rejecting imports of engine-specific
dependencies. It fails against beta138 and passes after the import-boundary fix.
Publication and installed-host qualification remain separate from source checks.
