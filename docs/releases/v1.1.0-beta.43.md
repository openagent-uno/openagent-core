# Core and SQLite beta43

Core and its SQLite adapter use the canonical package version `1.1.0b43`.
The adapter pins exactly that Core version. This is the successor to the
development candidate `1.1.0b43.dev2026110201`; old wheels remain immutable.
Hosts with a prerelease-only history policy can adopt this beta without
loosening downgrade protection or admitting unknown development version forms.

The release includes the generic [discovery presentation v1](../discovery-presentation.md)
contract, with bounded authorized hints, exact opaque references and unchanged
dispatch, revocation and pagination. Other independently versioned components
retain their existing versions and bytes.

Release qualification runs the real discovery presentation and package metadata
contracts, then verifies both freshly built wheel metadata and RECORD digests.
Package publication, downstream signed bundles, full host memory qualification
and real provider acceptance are separate results.
