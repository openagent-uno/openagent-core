# OpenAgent Core 1.1.0 beta 62

[Staged completions](../staged-operations.md) support up to three inference
attempts when the output fails JSON or schema validation. The attempts share the
stage deadline and its authorized evidence. The default remains one attempt
with the same checkpoint digest. A provider error still ends the step.

Core, SQLite, gateway and Python SDK advance together to `1.1.0b62`.

The [release](https://github.com/openagent-uno/openagent-core/releases/tag/v1.1.0-beta.62)
includes the wheel manifest and the installed-engine qualification receipt.
