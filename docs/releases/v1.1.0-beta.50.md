# Core 1.1.0-beta.50

Optional asynchronous session summaries have a ten-second default provider
budget. Hosts can configure `SessionSummaryManager.async_timeout_seconds` or
explicitly opt out with `None`. Expiry cancels and awaits the provider call,
retains the previous summary and does not turn the user's successful answer into
an error. Caller cancellation still propagates; no summary task outlives its
own turn. Synchronous generation retains its provider transport timeout.

The runtime adapter preserves the error type when reconstructing terminal
stream and collected-run failures. Quota exhaustion, throttling and credential
failures retain stable categories; public messages remain diagnostic-free.

Regression coverage includes expired summaries, provider cleanup, explicit
cancellation, fast updates, provider timeout identity and Agent/Team terminal
error classification. The wheel builder checks the runtime version constant
before building a cohort. Native permission qualification covers actual Linux and Windows CI plus the
installed pure Python wheel on macOS, without a local build. See the
[exact qualification receipt](../qualification/async-summary-2026-11-06-b50.json).

Beta49 did not pass the version-consistency release gate and was not published.
Its tag is retained unchanged; beta50 corrects the stale runtime version.
Publication and installed host acceptance remain separate evidence.
