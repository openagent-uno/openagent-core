# Core beta 133 — host-authorized subscription grants

Hosts that keep credentials in central encrypted custody can invoke the shared
Claude/Codex protocol with an exact ephemeral access grant. No refresh material
is copied into a local store, and account management mutations are refused.
OAuth exchange/refresh now has one shared transport and a public host contract
with explicit redirect and scope, preserving native sign-in defaults.

The shared error contract retains bounded quota/reset/retry metadata and removes
upstream messages from public host errors. Failed or truncated inference streams
cannot manufacture a successful completion. Grant streams require completion;
native Codex length-limited answers remain supported.

Local full public suite: 1,202 passed, 188 subtests passed, two skipped. Seventeen
new public regressions exercise exact identities, nonpersistence, shared protocol
inference, truncated streams, quota classification, off-loop OAuth, host redirects
and refresh scopes, and sanitized rejected credentials. Provider acceptance and
consumer release qualification remain separate.
