# Core beta41 — same-task MCP partial-entry rollback

The four distributions are Core, SQLite,
gateway and Python SDK `1.1.0b41`; their Core dependency pins agree. The base
Core dependencies remain empty. Qualification passes 669 full-suite tests and
97 subtests, 87 focused tests, and 15 installed-wheel regressions (the six new
MCP cases plus nine existing SQLite lifetime cases). Wheel RECORD entries and
source-byte equality are verified; all 397 packaged Python files parse as
Python3.11. Publication integrity is recorded separately for the actual assets.

An MCP handshake can time out after its transport and ClientSession contexts
have entered. Python's AsyncExitStack registers the toolkit's exit only after
its `__aenter__` returns, so a failed entry previously left no exit callback.
The public beta40 pool attempted to close that empty stack. Later asynchronous
generator finalization could then leave workers alive or exit AnyIO scopes
from a different task.

MCPTools now rolls back its own failed entry immediately on the same supervisor
task. Session teardown always precedes an attempted transport teardown, even
when the former raises. Owned references are released on either outcome;
startup exceptions and cancellation retain their original identity. Explicit
close also handles partially entered resources rather than relying on the
initialized flag. No tool call or uncertain mutation is retried by this fix.

Six new focused cases use actual MCPTools/pool lifecycle with owned synthetic
transport/session contexts containing real AnyIO task groups. They cover failed
entry, session-exit failure, handshake timeout, caller cancellation, reconnect
partial failure and ordinary teardown. They assert original task ownership,
reverse cleanup order, released workers and cleared references. These tests
pass with the related MCP reconnect/catalog and management suites (87 total),
and the full public and installed-wheel qualifications above.

Capability-host remains `1.0.0b3` and must reuse the exact public beta40 wheel;
module beta37 bytes and Host B7 bundles remain immutable. No Host rebuild or
qualification inheritance is implied. New wheel RECORD checks, installed
consumer qualification, signing and publication are separate release gates.
