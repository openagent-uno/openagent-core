# Core 1.1.0 beta117

Images reach Claude models behind a proxy.

- A `vision` entry in a model's `capabilities` now counts as image input.
  Rows registered with a text-only `input_modalities` next to the provider's
  own `vision` capability used to drop the user's images: the model got only
  attachment references and could not see them.
- Without metadata, every Claude generation from 3 onward (including Opus 5,
  Sonnet 5 and Haiku 5) defaults to text, image and file input. The previous
  list stopped at the 4 generation.
