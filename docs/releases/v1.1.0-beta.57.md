# OpenAgent Core beta57

Hosts can opt into model-facing calls by exact source ID and tool name for a
bounded list of known destinations. Each call uses the current authorized
catalog binding, records normal invocation events and preserves MCP result
projection, including authorized video frames. The default discovery surface
continues to expose the original four functions. See the
[named call contract](../discovery-presentation.md#opt-in-named-calls).

Core, SQLite, gateway and Python SDK advance together to `1.1.0b57`.
The independently versioned module wheels retain their versions.

The [release](https://github.com/openagent-uno/openagent-core/releases/tag/v1.1.0-beta.57)
includes the exact source and wheel digests, installed-engine qualification and
test reports. Focused fixtures cover authorization, revocation, exact destination
selection and chronological video frames through the streaming tool loop. Live
model and host acceptance are separate checks.
