# Core beta141 — offline conversion from remote to embedded subscriptions

The public `localize_subscription_accounts` migration converts explicitly
reviewed remote connections in place, preserving account/model IDs, toggles,
defaults, budgets, fallback groups, protocol overrides and session references.
A stopped-writer source digest and exact account-to-store mapping are required.
Shared private directories keep one rotating store and admission lane across
host databases; individual credential-file symlinks are rejected. Existing
conflicting files are never overwritten, unused accounts remain preserved,
and transaction failures remove only newly created destinations.

The embedded inference and storage contracts are unchanged from beta140.
This migration can run in an independently qualified administration environment;
consumers already on beta140 do not need a runtime replacement to use the
resulting native connections. Publication and live host acceptance are separate.
