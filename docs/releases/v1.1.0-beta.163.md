# Core 1.1.0 beta 163

Repeated reads of an unchanged document revision now lead to a bounded answer in the asynchronous native and JSON Schema model loops. The tool executes and publishes a fresh authorized receipt on every read. The model can choose other operations after two matching reads. A third consecutive match triggers one final answer pass after the runtime checks the current head and live permissions. Intervening work, transient failures, parallel calls and new turns break the sequence. [Capability discovery](../capability-discovery.md)

The document vault module advances to 1.1.0b6 and its full bundles to 1.1.0b11.
