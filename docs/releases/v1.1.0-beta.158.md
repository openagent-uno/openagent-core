# v1.1.0-beta.158

SQLite-to-PostgreSQL migration can associate archived multi-turn engine sessions with their canonical admissions when both sides retain matching, complete engine envelopes. The opt-in covers tool calls and results, failed runs and engine restarts. The operator verifies identity, owner, session, terminal state and every archived field before it records a reference and digest. The sealed archive retains the full payload. [Migration options and verification](../storage-tenant-domains.md#preserve-engine-session-envelopes-during-a-runtime-migration).
