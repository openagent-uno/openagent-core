# Core 1.1.0 beta89

MCP sources can reference host secrets instead of storing credentials. A header
value (remote sources) or environment value (stdio sources) may contain
`${secret:OPENAGENT_MCP_SECRET_<NAME>}`; the server replaces it with that
variable from its own environment when the source connects. Only the reserved
`OPENAGENT_MCP_SECRET_` prefix can be referenced; an unresolvable reference keeps
the source unavailable with failure code `secret_unavailable`. The value never
reaches the catalog, status, logs or model context.

`mcp-manager` `add_custom_mcp` and `update_mcp` accept `headers`, and the
manager tools show header values masked unless they are reference-only. See
`docs/mcp-secret-references.md`.
