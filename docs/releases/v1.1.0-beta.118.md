# Core 1.1.0 beta118

A model's media support follows its provider.

- `metadata.input_modalities_source` records whether a model's
  `input_modalities` came from the provider's catalog (`provider`), the
  model-family default (`default`) or a person (`manual`).
- `ProviderModelAdmin.create_model` reads the provider's declaration when a
  language model is registered. The new `refresh_capabilities(context,
  provider_id)` re-reads it for every language model of a provider (after a
  sign-in or a new endpoint) and returns what changed. A `manual` declaration,
  and a model the provider does not list or cannot be reached for, are kept.
- `update_model` marks `input_modalities` set without a source as `manual`;
  the source `auto` hands the declaration back to the provider.
