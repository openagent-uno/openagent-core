# Core 1.1.0 beta93

A run's stored preview keeps its conclusion.

- `task_runs.output` and `task_runs.error` of scheduled tasks, and the output of
  event deliveries, kept the first 4000 characters: the opening narration of an
  unattended run, never its closing summary and state of the work.
- Previews now keep the end of the text, prefixed by
  `[… N earlier characters omitted; full transcript in the run's session …]`
  when cut, within `RUN_PREVIEW_CHARS` (8000). An agent `output_retainer` still
  decides event previews. See `docs/run-output-preview.md`.
