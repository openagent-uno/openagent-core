# Embedding beta 184

Some providers send a successful HTTP response and report an error in the
first server-sent event. The OpenAI-compatible streaming adapter now reads the
structured error status. A 401 received before any output lets the existing
account router try an authorized backup for the same model. The synchronous
and asynchronous paths follow the same rule. After any output the stream ends
with the provider error, preserving the partial response without replay.

The [account routing guide](../provider-accounts-and-backups.md) describes
which accounts can be selected and how usage is attributed.
