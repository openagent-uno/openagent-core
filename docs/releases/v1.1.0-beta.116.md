# Core 1.1.0 beta116

A voice note gets a text reply.

- `StreamSession` speaks a reply only when the session has speech on
  (`speak_enabled`, for example a live voice conversation). A transcribed
  voice note (`source="stt"`) used to turn speech on for its reply even in a
  silent session, so chat apps and channels received an unrequested
  text-to-speech copy of the answer. `source="stt"` still enables the instant
  barge-in.
