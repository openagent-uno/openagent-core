# Embedding release 1.1.0-beta.155

Hosts can retain a run's status and cursor after the run has read protected memory. The live runtime keeps the text and rechecks the viewer's current access when it displays the conversation. Embedded management screens can bind the signed-in actor to the exact session for that check. [Document access](../memory-access.md)

SQL vault editors can page note metadata by path and search filenames independently from content. The listing provides UTF-8 byte size, note type, tags and the date recorded for the current revision when the source provides one. Existing vaults can be read immediately, with indexed metadata refreshed by new writes or an explicit index rebuild. [SQL vault editor](../memory-access.md)
