# Core beta38 and independent capability-host beta2

The release cohort is `openagent-core`, `openagent-storage-sqlite`,
`openagent-gateway` and `openagent-sdk` at `1.1.0b38`, plus the independent
`openagent-capability-host` at `1.0.0b2`. The latter pins the independently
versioned Tools `openagent-tool-protocol==1.0.0b2`. Unchanged published modules
retain their versions and existing public bytes.

This integration starts at public main `c77cf31b7622e1eb95213433618ab6838e1513d1`.
It adds the three reviewed opt-in management commits and only the scoped
capabilities feature delta. The synthetic snapshot parent is not included in
release ancestry. SQLite worker cancellation/draining and dead-session MCP
reconnect remain on the public-main implementations. Agent stream execution
retains actionable `RunTurnError` categories and the canonical content format
while applying the optional MCP Apps prompt-context scope.

The changes add instance-owned management composition, complete bounded MCP
list pagination and explicit engine refresh, generation-bound stdio catalog
notifications, scoped MCP Apps resources/model context, and durable tool display
projection. Core does not add a renderer, native UI, product identities, provider
credentials or default approvals.

Earlier receipts under `docs/evidence/` describe their recorded source snapshot;
they do not attest this integrated release. Before publication, qualify the
integrated source including SQLite cancellation, reconnect and management
regressions, build only the five changed distributions from a clean committed
snapshot, and record exact commit, wheel bytes and SHA-256 digests. Signed
desktop installers, public delivery and product deployment remain separate gates.
