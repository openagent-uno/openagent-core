# Core beta 131 — preserve versioned Claude aliases

Claude subscription translation accepts versioned short family aliases such as
`opus-4-8`, sending the same generation as `claude-opus-4-8`. Persisted model IDs,
pins, defaults and historical references remain unchanged. Full identifiers and
explicit model maps pass through unchanged; no alias selects a newer generation.

Signed-in Claude model discovery reads the account's authenticated provider
catalog, including pagination. Failed discovery does not silently substitute a
stale version snapshot. Unknown model families receive text-only input metadata
until the provider or operator declares additional capabilities. Construction
and the pre-sign-in preview remain inert and credential-free.
