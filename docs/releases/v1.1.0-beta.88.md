# Core 1.1.0 beta88

Adds the opt-in channel message capability (`ChannelMessageCapability`,
`ChannelMessageSink`). A host that registers a sink exposes
`list_channel_destinations` and `send_channel_message`, so an agent can post
text and files on its own initiative in conversations the host admits. Hosts
without a sink are unchanged. See `docs/channel-messages.md`.
