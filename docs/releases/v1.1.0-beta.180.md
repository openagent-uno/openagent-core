# Embedding beta 180

Text streams and local audio can run with their own dependencies. When
transcription or synthesis uses a LiteLLM speech adapter, the adapter imports
the SDK on a worker thread so other sessions can continue.

For streaming synthesis, the adapter forwards each nonempty chunk as the SDK
yields it. The SDK can return an async byte iterator directly or through an
awaitable. See the [audio host contract](../audio-host-contract.md).
