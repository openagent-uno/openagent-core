# Core beta147

Automatic text selection recovers through eligible configured language models,
with fresh model-use authorization, strict budget/capability gates, a bounded
first-output wait and temporary connection health. Explicit pins and configured
backup precedence remain intact. Typed image, transcription and speech routes
share catalog eligibility instead of requiring manual provider selection.

Fallback copies retain borrowed account transports. Actual response identity
and reported usage follow the responding model. Streaming cancellation closes
nested iterators; partial output and recorded tools are never replayed.
Image recovery distinguishes a generation connection failure from a failed
download after acceptance. Speech recovery retains consumed text and pins the
successful voice/encoding for the rest of an utterance.

Source regressions include the ordinary dispatcher, real SDK HTTP against a
local authenticated fixture, SQLite usage attribution, isolated audio workers,
image generation acceptance boundaries, speech replay and account transports.
These deterministic fixtures do not certify commercial-provider availability,
live messaging channels, microphones or host deployment. Publication and host
acceptance are separate gates; exact package evidence is in the release manifest
and qualification receipt.
