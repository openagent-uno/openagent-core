# Core 1.1.0 beta121

A goal that is too long is refused, and a host can leave out the computers guidance.

- A goal objective longer than 4000 characters is now an error that gives its
  length (`GoalStore.set`, `GoalStore.update`, `/goal`). It used to be cut at
  the limit without a word, which silently dropped the end of a long goal.
- tool-discovery 1.1.0b4 (with openagent-modules and openagent-modules-full
  1.1.0b7): new module option `computers_guidance` (default `true`). With
  `false` the "Computers and browsers" rule (`core.computers`) stays out of
  the prompt, for a host whose agents have no shell, browser or screen
  tools on a host or a connected device. Unknown options are refused.
