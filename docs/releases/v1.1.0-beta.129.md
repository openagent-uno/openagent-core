# Core beta 129 — stable subscription renewal

Subscription sign-in preserves the connection's chosen account name when the
host omits a redundant name field. Renewing or renaming an existing account
keeps its stable account id and enabled state; text and image connections
sharing its rotating store retain their binding and consistent labels.

This follows beta128's built-in protocol, model-connection, budget and
responsiveness contracts. Every adapter and host inherits the correction
through Core rather than reproducing account-renewal policy in a client.
