# Core 1.1.0 beta53 candidate

This source candidate includes the merged compact cross-source BM25 discovery,
current-session history recovery and honest lossy-compaction continuation rules.
Sessions is independently versioned as `1.1.0b3`; the compatibility/full-profile
packages are `1.1.0b4`. The generic reference example follows the Sessions pin.
Core, SQLite, gateway and Python SDK remain one `1.1.0b53` cohort. Unchanged module
and capability-host wheels keep their independent versions and byte identity.

## Qualification correction

The earlier nine broad-suite failures were observed in a development environment
with installed Core beta24, Tool Protocol beta1 and global TypeScript 4.7. The
isolated audio subprocess therefore executed an older worker, not the checked-in
FD-isolated implementation. Tool Protocol beta2 already contains the metadata
contract; the TypeScript SDK requires its declared 5.9 toolchain. No runtime
type cast, weakened audio protocol or relaxed capability validation was needed.

The new `packaging/qualify.py` installs the complete candidate wheel closure in a
fresh environment, checks provenance/import versions and dependency consistency,
and uses the locked TypeScript 5.9.3 compiler. Both release workflows use this
same gate instead of borrowing a standalone installation and replacing only four
packages. The audio HTTP test explicitly verifies its isolated worker version.
See [the procedure](../USAGE.md#reproducible-engine-qualification).

The development candidate passed **792 Python tests and 128 subtests, with two
platform skips**, plus the Node SDK unit test and live HTTP gateway fixture.
This was a dirty-source development build, not a published release. The final
clean source/tag and native/installed package gates remain separate evidence.

## Retrieval checks and limits

A separate operator-selected remote embedding backend (`bge-m3:latest`) retrieved
all three correct synthetic canonical conversations in Italian after a four-day
timestamp gap and SQLite reopen; exact original detail was readable. No embedding
model weights were loaded on the control machine. No model or endpoint is enabled
by this release, and descriptor-profile recall still honors its existing scope.

In one synthetic 193-tool/eight-source fixture, source listing + targeted scoped
discovery + describing the selected tool produced 336 `cl100k_base` result tokens;
global targeted discovery + describing the same tool produced 179, saving 157.
This compares result payloads of two already-deferred strategies, not all-tools
upfront. It excludes prompts, cache pricing, reasoning, generation and retries:
**it is not a complete-task cost reduction or a live Telegram qualification**.
