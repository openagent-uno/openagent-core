# Core 1.1.0 beta122

A turn rebuilt from the run journal keeps the model that answered.

- `SessionInspection.transcript` rebuilds a turn from the run journal when the
  provider mirror was never saved. Those turns now carry `model`, taken from
  the run's recorded model (`session_runs.model`, filled since beta119) or,
  for older runs, from the provider run envelope. They used to come back
  without one.
