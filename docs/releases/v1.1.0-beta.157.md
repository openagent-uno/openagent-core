# v1.1.0-beta.157

The SQLite-to-PostgreSQL operator can now attest archived single-turn engine sessions against canonical private runs. The candidate records the original row and run digests, preserves owner and session isolation, and retains complete engine envelopes in the verified private archive. The opt-in rejects unsupported or conflicting histories before activating a runtime. See [the storage migration contract](../storage-tenant-domains.md#preserve-engine-session-envelopes-during-a-runtime-migration).
