# Core 1.1.0 beta 160

Embedded hosts can select trusted user text from a request envelope for optional automatic document recall. Ranked lexical overlap finds note references within the authorized space. Scope, audience, live note membership and original read receipts govern publication. The explicit search API keeps its all-term semantics. [Document recall](../architecture.md#automatic-recall-from-document-memory)

Durable document maintenance accepts an optional transactional scope enrollment check before an ordinary edit is queued or a manual or scheduled occurrence is admitted. The existing queue lease, grant checks, revision guard and source-specific activity review also apply after a restart. [Scheduled document maintenance](../architecture.md#scheduled-document-vault-dreams)

Document tools validate relative paths before recording an attempted effect. A conditional write that loses a revision race returns a structured error and records that the note was unchanged, allowing the caller to reread before submitting a new change. The versioned vault module is 1.1.0b4 and the full module bundle is 1.1.0b9.
