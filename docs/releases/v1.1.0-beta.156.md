# OpenAgent Core 1.1.0-beta.156

A shared HTTP MCP service can authenticate discovery and execution separately for each tenant, session and operation through a host-supplied grant resolver. The runtime opens an isolated MCP session per exchange and revalidates its grant before returning data. The network test exercises overlapping callers and revocation during a tool call.
