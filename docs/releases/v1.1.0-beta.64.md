# OpenAgent Core 1.1.0 beta 64

An embedding host can configure the speech capability's provider deadline
with the keyword-only `timeout_seconds` parameter. The default remains
120 seconds. The range is 0.1 to 3600 seconds. This lets a host budget for
provider preparation while keeping the existing authorization and artifact
publication checks. An enclosing run or stage can apply a shorter deadline.

The public speech tests exercise both deadlines through the runtime catalog.
They verify that a timed-out call runs once and creates no artifact, and
that a call admitted with a longer window publishes a canonical audio
artifact. The fixtures make no real provider requests.

Core, SQLite, the gateway and the Python SDK advance together. The
independently versioned modules retain their published versions.
