# Embedding beta 170

Manual task and workflow launches bind a caller key to an exact definition, input, trigger and projected run ID. A duplicate uses the existing receipt and a conflicting submission raises `IdempotencyConflict`. Queued work survives a restart. The scheduler checks the original grant when dispatching the occurrence and prevents an interrupted, started operation from running a second time. [Automation host contract](../automation-host-contract.md)

An authorized stop closes a queued reservation before dispatch or forwards cancellation to its running owner. During shutdown, the runtime rejects new work from a draining module while allowing admissions already in progress to finish.

The synchronized Core, gateway, SQLite, PostgreSQL and Python SDK packages are `1.1.0b170`. The JavaScript SDK and independently versioned modules retain their existing package versions. Published artifacts belong to the embedding channel.
