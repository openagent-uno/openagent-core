# Core 1.1.0 beta114

A device can be lent to its owner's automations.

- New `DelegatedDeviceSource` with `register_delegated_device_capabilities` and
  `revoke_delegated_device_capabilities` (`openagent_core.mcp.catalog`). A host
  can register a connected device for its owner's deferred, authorized runs
  after an explicit consent. The source has no lease and never rides inside an
  `ExecutionContext` (deferred work still cannot carry temporary
  capabilities); every discovery and call requires a deferred run with a
  delegation, no ingress, and that owner as initiator and authority on that
  agent, and the host's source authorizer must recheck the consent each time.
  The interactive path is unchanged and still refuses deferred work.
- The tools rule now says that an automation reaches a device only when its
  owner lent that device to it.
