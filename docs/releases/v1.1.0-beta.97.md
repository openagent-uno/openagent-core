# Core 1.1.0 beta97

Agents can see and find their own tools.

- Every run's system prompt ends with a plain-text `<capabilities>` section
  built from the turn's authorized catalog: each source and the computer or
  account it acts on, what it is for, its tool count and, for small sources,
  its tool names. Before, the deferred catalog showed only the discovery tools.
- `tool_search_list_servers` returns source descriptions and matches every
  query word against name, target, description and older names
  (`scheduler`, `workflow-manager`, `memory-search`…).
- `tool_search_list_tools` resolves older source names, stems search words,
  ignores stopwords, searches the source's description too, and suggests
  sources when nothing matches.
- External MCP servers' own `instructions` describe them in the map when the
  framework has no description.
- Prompt rules no longer point at a "catalog above" or "trimmed" tools, use
  current source names, and no longer name other products or projects.
See `docs/capability-discovery.md`.
