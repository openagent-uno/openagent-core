# Core 1.1.0 beta100

A shorter, ordered, consistent system prompt.

- Prompt blocks are ordered by purpose (identity, principles, tools, routing,
  memory, history, automation, delegation, files, skills, communication; host
  blocks after), not by module name. See `docs/system-prompt.md`.
- Framework and module text rewritten: about 8,450 → 3,730 tokens. Agnostic,
  current source names, the `<capabilities>` map as the starting point for
  tools, no stale claims, delegation contradiction resolved (the host decides;
  workers never re-delegate). Memory rules keep every non-negotiable in about a
  quarter of the space; detail moved into the vault tool descriptions.
- Discovery and session tools say when to use each.
- New prompt lint tests: current source names only, size budgets, neutrality.
- Modules: events, mcp, scheduler, workflows, vault, tool-discovery 1.1.0b2;
  search 1.1.0b3; sessions 1.1.0b4; openagent-modules(-full) 1.1.0b5.
