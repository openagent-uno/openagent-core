# Core 1.1.0 beta119

A run records which model answered.

- When a provider run envelope is attached to its admitted run,
  `session_runs.model` and `model_provider` are now filled from it (a value
  already recorded is kept). They were left empty for runs admitted through
  the public runtime, so history could not say which model answered a turn
  after a reload. New `apply_run_envelope` in
  `openagent_core.memory.operational.repository`.
- Runs stored before this release keep an empty column; a host can fill it
  once from `raw_envelope_json`.
