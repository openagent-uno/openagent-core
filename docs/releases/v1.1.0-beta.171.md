# OpenAgent Core 1.1.0b171

Hosts can attach a transactional observer to individual SQL vault writes,
deletions and erasures. The observer receives the verified operation and
revision metadata without note contents. Domain projections or receipts
written through the supplied connection commit with the vault change.
A stale revision, observer exception or revoked authorization leaves the
mutation uncommitted. Existing hosts can omit the observer.
