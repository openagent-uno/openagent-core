# OpenAgent Core 1.1.0 beta 61

[Staged completions](../staged-operations.md) accept bounded inline image evidence
from an exact authorized catalog tool. The isolated inference receives the images
in MCP result order. The stage checkpoint stores the structured decision, and
ordinary access rules apply to the canonical tool receipt. A read marked
idempotent may be replayed after an interrupted stage.

Core, SQLite, gateway and Python SDK advance together to `1.1.0b61`.
This release retains the existing staged video extractor and desktop interaction contracts.

The [release](https://github.com/openagent-uno/openagent-core/releases/tag/v1.1.0-beta.61)
includes the wheel manifest and the installed-engine qualification receipt.
