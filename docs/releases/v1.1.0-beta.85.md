# Core 1.1.0 beta85

A provider stream that fails before producing any output with a transient error
(no status code, or 5xx: a dropped connection, a stream that errored before its
first event) is retried once on the same model before configured fallbacks.
A single network interruption no longer ends a long agent turn when the model
has no retries and no fallback is configured. Rate limits, context overflow and
other 4xx errors keep their existing handling, and nothing that already emitted
output is ever resent. See `docs/model-stream-recovery.md`.
