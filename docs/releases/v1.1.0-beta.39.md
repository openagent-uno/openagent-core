# Core beta39: exact MCP connection lifetime

Core, SQLite, gateway and Python SDK advance to `1.1.0b39`. The independent
capability-host stays at `1.0.0b2`: the beta39 release reuses its exact published
beta38 wheel bytes and records their original source commit in the manifest.
Unchanged modules retain their published versions and bytes.

A pool reconnect reuses the toolkit object. Previously, an identical tools/list
catalog could therefore leave an old MCP App view and tool reference usable on
the replacement connection. MCPTools now publishes a random opaque capability
generation only after its complete catalog belongs to the current session.
Pool definitions include that host-owned generation, overriding remote metadata.
A changed session, incomplete catalog or failed refresh invalidates old bindings.
The generation contains no credential, principal or transport session identifier.

Cached view replies authorize the current binding before returning. Resource and
app calls check the same generation across credential acquisition and I/O. Model
tool calls also check after readiness and ping, immediately before dispatch and
before returning. Catalog admission also rechecks after the durable ledger write
and publication policy; stale admission closes that ledger with a terminal
non-retryable failure. A replacement during either wait cannot receive the old tool
mutation, and a replacement during I/O cannot publish or replay its result.
Calls outside catalog admission retain the existing dead-session recovery behavior.
Discovery on an unchanged connection retains references and Function identity;
fresh discovery and a new view work after a successful reconnect.

The regression suite uses two owned mocked MCP sessions with identical catalogs,
including completed request IDs, changed-session reads, mutation oracles, failed
refreshes and credential/readiness/ping races. It performs no native UI, network
or provider calls. Product deployment, signed installers and external services
remain separate qualification boundaries.
