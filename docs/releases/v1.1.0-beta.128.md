# Core beta 128 — provider connections and built-in subscriptions

Claude and Codex subscription OAuth, credential rotation, protocol translation,
streaming and admission now live in optional Core services. Independent API
connections and exact subscription accounts can share one vendor without
sharing credentials or model settings. Text, image, TTS and STT models belong
to connections through the same catalog contract.

The public model form schema is capability-specific. Existing provider ids,
model references, pins, defaults and budget groups survive explicit offline
legacy-store adoption. Shared text/image accounts use one rotating store.
See [the contract and migration gates](../subscriptions.md).

Provider budget queries use exact identity and a covering window index.
Concurrent identical spend reads share active work without retaining results.
On a deterministic 100,000-row fixture, 24 provider checks improved from
706.10 ms to 116.79 ms median (three samples per version, about 6.05×).
This measures one Core storage path, not every operation or production latency.
Catalog materialization was already below 1 ms on the same 96-model fixture.

Source qualification: 1,148 tests, 188 subtests passed; two optional tests
skipped. Additional translation, deadline, billing-coverage and process-safe
refresh regressions passed separately. Installed-wheel and native qualification
are release gates; CI receipts certify the published artifact cohort.
