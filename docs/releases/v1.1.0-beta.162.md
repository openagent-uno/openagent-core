# Core 1.1.0 beta 162

Hosts can narrow capability sources for one authenticated turn. A conversation with an empty selection omits the native tool broker. Discovery and dispatch both enforce the selection. [Capability discovery](../capability-discovery.md)

Automatic document recall ranks matching notes across the authorized space before limiting the result. Explicit searches retain their existing query semantics. A writable document vault instructs the agent to save a lasting preference volunteered in conversation. The structured tool protocol carries those standing instructions through to the model. [Document vault](../architecture.md#host-owned-document-vault)

The document vault module advances to 1.1.0b5. The full module bundle and its compatibility package advance to 1.1.0b10.
