# Core 1.1.0 beta99

Session loops, and each capability source shown once.

- A scheduled task can run inside a conversation (`target_session_id`): every
  firing is a top-level turn of that chat, admitted with the task's captured
  delegation, never a child session. `create_scheduled_task(...,
  in_this_conversation=True)` lets the agent loop its current conversation.
  Additive migration of `scheduled_tasks`. See `docs/session-loop.md`.
- The capability map, `list_servers` and cross-source tool search hide a
  compatibility alias (`scheduler`, `model-manager`, `mcp-manager`…) whose
  canonical source is present; the alias stays resolvable and callable.
