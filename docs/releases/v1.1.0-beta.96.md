# Core 1.1.0 beta96

Session goals: a conversation keeps working until its goal is achieved.

- `/goal <objective>` gives one conversation a goal. While it is active the
  objective is in the system prompt and, when the agent loop would end the
  turn, the same run continues in the same session with a reminder, bounded by
  the goal's continuation budget (default 20, `/goal max <n>`).
- The agent closes the goal with a `[goal: achieved] <outcome>` line or hands
  back with `[goal: blocked] <reason>`; a spent budget pauses the goal.
- `/goal status | pause | resume | done | clear` manage it from any host that
  runs session commands; `openagent_core.session_goal.GoalStore` lets hosts
  expose it in their own UI and API. See `docs/session-goal.md`.
