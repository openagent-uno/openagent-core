# Core 1.1.0 beta91

Background model choice no longer depends on a vendor name.

- The compaction summariser's fallback, when the session's own provider cannot
  summarise, picks by properties: the operator's choice
  (`OPENAGENT_COMPACTION_FALLBACK_MODEL`), then a self-hosted row of another
  provider, then the cheapest enabled row of another provider (ties keep
  configuration order). The provider that just failed is never retried.
  `cheapest_enabled_model()` accepts `exclude_provider`.
- The quality-monitor judge follows the same rule: self-hosted first, then the
  cheapest enabled row; `OPENAGENT_QUALITY_MONITOR_MODEL` still overrides it.
  Before, both preferred one specific vendor by name.
- Comments and docstrings across budgets, runtime errors, metrics, dispatch,
  storage, credentials and catalog describe providers generically.
- `docs/migration/sources.json` uses `<workspace>/…` instead of machine paths.
