# Core 1.1.0 beta 78

Source discovery can filter by source name and destination label before paging.
Its model contract requires complete discovery before reporting a missing device
and retaining the requested destination through permission failures and retries.

Successful tool images can receive current-session attachment references through
the host's optional admitted-byte publisher. The final answer must explicitly
select the exact returned marker; image previews alone do not deliver files.
Publication rechecks session authority and unavailable previews preserve a valid
answer. Existing filesystem publishers retain their configured read authority.

Qualification covers source paging, hidden and revoked destinations, exact image
bytes through CAS and final projection, reader failures, final selection and
revocation. Live provider, device and channel acceptance is recorded separately
by the deploying host.
