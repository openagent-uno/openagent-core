# OpenAgent Core beta58

An authenticated run can execute a trusted host's versioned staged operation.
The engine invokes exact catalog tools, polls bounded job receipts and validates
structured stateless inference, including previews of authorized embedded
video. It checkpoints successful stages. A new authorized run can continue a
failed or interrupted operation after checking its original input and identity.
See the [embedding contract](../staged-operations.md).

Core, SQLite, gateway and Python SDK advance together to `1.1.0b58`.
Independently versioned module wheels retain their versions. The SQLite adapter
stores checkpoints in its existing operational event table.

The [release](https://github.com/openagent-uno/openagent-core/releases/tag/v1.1.0-beta.58)
includes the source and wheel digests, installed-engine qualification and test
reports. Focused fixtures cover session authority, receipt polling, media
projection, malformed completion, cancellation and continuation after restart.
