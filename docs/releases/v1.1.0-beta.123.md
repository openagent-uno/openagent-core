# Core 1.1.0 beta123

The live view says which model answered each run.

- `SessionInspection.live_runs` now returns `model` and `model_provider` on
  every run (`null` when unknown), from the run's recorded values or, for runs
  stored before beta119, from the provider run envelope. The envelope is read
  in SQL only for those runs. A host no longer needs to label live snapshots
  itself.
