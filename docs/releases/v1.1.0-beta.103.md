# Core 1.1.0 beta103

Call any authorized tool by name.

- `DiscoveryPresentation(named_calls="authorized")` lets the model call any
  tool it may discover with `tool_search_call_named_tool(source_ref,
  tool_name, args, target_label=None)`. The name resolves through the same
  authorized catalog as a `tool_ref` and stays valid across reconnects and
  restarts. Default stays `"listed"`. See `docs/discovery-presentation.md`.
- A `tool_search_list_tools` page of up to three tools includes each tool's
  `input_schema`.
- The `<capabilities>` section and the `core.tools` rule describe the named
  call when the host enables it.
