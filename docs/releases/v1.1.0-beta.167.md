# Embedding beta 167

Hosts can register a bounded readiness check before ordinary run admission. Clients opt in per request with `admission_policy=defer-unready`. A waiting gateway returns HTTP 503 with a typed reason and a matching `Retry-After` in seconds. The Python and TypeScript SDKs distinguish this decision from an uncertain network outcome. The caller retains the same run ID and idempotency key when retrying.

A caller with permission to cancel in a session can reserve cancellation before admission. If admission wins the race, the caller receives the existing run receipt. Already accepted runs keep their original digest and are available under their current read permissions.

The release manifest identifies the Python SDK wheel and the installable `@openagent/sdk` version `1.0.0-beta.4` tarball by SHA-256. The public installation tests exercise the SDKs over HTTP, SQLite and PostgreSQL.
