# Core beta 132 — subscription capability identity and JSON transfer

Versioned Claude subscription aliases now resolve the same provider catalog
entry during model registration and capability refresh as during inference.
Short family/version identifiers inherit conservative image/file capabilities;
manual declarations and persisted identifiers remain unchanged. API model names
are not reinterpreted as subscription discovery aliases.

Offline credential adoption supports independent host databases with coincident
provider ids that explicitly reuse one private credential directory and account
owner mapping. Existing files and stopped-writer snapshots are still verified.

The optional gateway exports negotiated, off-thread buffered JSON compression.
HTTP identity clients and streaming protocols retain their existing behavior.
See the usage guide for exclusions and measurement limits.

Local targeted regressions cover real HTTP bytes, cookies, negotiation, worker
execution, streams, authorization failures, catalog refresh, alias translation,
and shared rotating credentials. Production latency acceptance is separate.
