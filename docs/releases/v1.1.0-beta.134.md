# Core beta 134 — validated subscription completions for host adapters

The public subscription service exposes `complete` and `stream_chat` so an
embedded host can relay the shared protocol without copying a provider client,
translator or SSE parser. Prefetch keeps early provider failures before a host's
HTTP success. Interrupted answers never manufacture a successful terminal frame.

Provider HTTP failures retain quota headers even for non-JSON bodies. Explicit
host settings preserve read deadlines without changing native defaults. Provider
redirects and implicit process proxy configuration cannot redirect credentials.
Raw SSE bounds include malformed and ignored lines; cancellation closes streams
and their sessions. Errors after partial output remain sanitized and are not
retried or followed by a success marker.

Local full public suite: 1,208 passed and 188 subtests passed, two skipped.
Additional public settings and read-deadline tests passed afterward; the complete
subscription/grant regression subset passed 41 tests. Installed release gates
qualify the final immutable source separately. Real provider and host acceptance
remain separate from protocol fixtures.
