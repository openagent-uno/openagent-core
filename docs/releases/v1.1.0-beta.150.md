# Core beta150

Streaming replies identify the model that actually answered after an account
rotation or model fallback. The dispatcher now asks the provider that handled
the session, preserving its resolved responder identity instead of returning
the original delegation target or a stale delegation from another cached
provider. Shared channel collectors receive that same terminal model value.

Session pins, accounts, model settings, budgets and response text are unchanged.
The change adds no host-specific configuration or duplicated channel logic.
See [provider accounts and backups](../provider-accounts-and-backups.md).

Regressions cover account rotation, session isolation and a real loopback
SDK/SQLite fallback through the agent, stream and shared channel collector.
Installed package qualification, publication and live channel acceptance remain
separate verification steps.
