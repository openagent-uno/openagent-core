# OpenAgent Core beta54

The embedding engine offers [optional video frame previews](../attachments.md#optional-video-frame-previews)
for admitted inline MP4 attachments. An eligible model with native video
support receives the original input. If no compatible native model is
configured, an eligible image model can receive up to three chronological
sampled frames per video and approximate timestamps. The samples cover the
visual content only.

The host explicitly configures trusted FFmpeg and FFprobe executables. The
extractor uses a temporary file with byte, duration, dimension and execution
bounds. Original attachments keep their host references, admission and
authorization. The same configuration applies to normal dispatch and to
explicitly pinned model runs.

Core, SQLite, gateway and Python SDK advance together to `1.1.0b54`. Sessions
stays at `1.1.0b3` and compatibility/full profiles stay at `1.1.0b4`.

## Qualification

Local exact-tag qualification passed 794 tests and 128 subtests, with two
skipped tests. A separate 45-test attachment and version run used the installed
Core wheel downloaded anonymously with the source import path disabled. The
synthetic three-color MP4 verified sample order, timestamps and actual pixels
through both model routes.

The [hosted release job](https://github.com/openagent-uno/openagent-core/actions/runs/42403843229)
passed native contracts on Linux, Intel macOS and Windows. The isolated hosted
engine suite passed with three skips, including the FFmpeg-dependent fixture
on a runner without FFmpeg. All 23 [published wheels](https://github.com/openagent-uno/openagent-core/releases/tag/v1.1.0-beta.54)
matched the [verified public manifest](../qualification/core-b54-public-2026-11-07.json).
Live model behavior and host deployment acceptance are separate checks.
