# OpenAgent Core 1.1.0 beta 66

The attachments toolkit can find and resend original files linked to the
current session, including files from earlier turns. A resend uses the same
stored artifact and follows the existing authorization and canonical delivery
flow. Discovery returns up to twenty filename matches without local paths.

The regression verifies that the attested final answer includes the original
artifact with identical bytes, without a new upload. Other sessions, deleted
artifacts and revoked access are covered. Provider delivery needs separate
host acceptance.

Core, SQLite, the gateway and the Python SDK advance together. The
independently versioned modules retain their published versions.
