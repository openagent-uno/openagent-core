# Core 1.1.0 beta87

Publishes `openagent-capability-host` 1.0.0b4. A model that issues several
mutating tool calls in parallel no longer gets every call after the first
refused with `lease_held`: a call from the principal that already holds the
mutating lease now waits a bounded time (30 seconds by default) for that lease
and runs after it, so the calls are serialized. Calls from a different principal
are still refused immediately. The package's `__version__` now matches its
metadata. Beta86's vault history recovery and beta85's transient stream retry are
included. See `docs/model-stream-recovery.md`.
