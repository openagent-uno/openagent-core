# Embedding beta 177

Hosts that submit an original file by artifact ID can look it up by the name the user saw in that conversation. If the same bytes have multiple names, an exact search uses only names admitted to the current conversation.

When reopening a saved conversation, clients can recover missing file cards from the accepted input or the assistant's final delivery. The SQLite reader uses the current session and file permissions on each request. A revoked file stays hidden. Older messages with existing parts keep their saved order.

These checks cover both incoming and returned files, including older terminal frames, read-only history after reopening, and interleaved text and tools.
