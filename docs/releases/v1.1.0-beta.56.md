# OpenAgent Core beta56

The embedding engine can give an image-capable model chronological frame
previews of an MP4 embedded in an authorized MCP tool result. Hosts opt in by
registering a bounded FFmpeg extractor. They can configure the sampling
positions to cover shorter visual events. The extractor preserves the MCP
wire result and never follows video links. See [tool result previews](../attachments.md#visual-previews-of-mcp-tool-results).

Hosts can also register an optional speech synthesis tool backed by their
configured voice service. It returns a private canonical audio artifact after
checking the current run and the host's write authorization. See [speech synthesis](../audio-host-contract.md#speech-synthesis-as-an-agent-tool).

Core, SQLite, gateway and Python SDK advance together to `1.1.0b56`. The
independently versioned module wheels keep their existing versions.

The release workflow builds wheels from the exact tag and attaches the source
and wheel digests, installed-engine qualification and test reports to the
[release](https://github.com/openagent-uno/openagent-core/releases/tag/v1.1.0-beta.56).
The test fixtures exercise the model input and authorized audio storage paths.
Live provider quality and host integration are qualified separately.
