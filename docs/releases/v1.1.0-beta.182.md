# Embedding beta 182

A local MCP source can need more time to initialize after a process restart.
When a stdio handshake times out at startup or after a disconnection, the pool
can start a longer handshake in the background. Other connected sources remain
available during recovery. Callers that reconnect during backoff share the
scheduled attempt. Recovered tools use their existing access rules.

See [MCP transport recovery](../mcp-transport-recovery.md) for the retry timing.
