# OpenAgent Core 1.1.0 beta 175

Model discovery, automatic routing and explicit model selection pass the
current turn's audience to the host authorizer. This also applies when a
delegated run selects its own model. A host that checks the exact recipients
can apply the same policy during model selection as it does when admitting
and publishing the run.

The host continues to decide which models the caller can use. A delegated
run retains the audience and capabilities granted to it.
