# OpenAgent Core 1.1.0 beta 65

A staged completion carries its exact JSON Schema in the stateless inference
request as well as the formatting prompt. A host can opt in to forwarding
object schemas in the OpenAI-compatible `response_format` field. Enable it
for endpoints qualified for that contract. Textual prompting remains the
default. The engine still validates responses and checkpoints only valid JSON.

The focused tests cover the HTTP request with and without the opt-in, the
schema and evidence delivered to staged inference, and the existing retry
and speech boundaries. Provider-specific acceptance remains with the host.

Core, SQLite, the gateway and the Python SDK advance together. The
independently versioned modules retain their published versions.
