# Core 1.1.0 beta 80

Transport-confirmed outgoing messages can be recorded through the public
`ConfirmedDelivery` and `Runtime.record_delivery` contract. They appear as
assistant messages in canonical history, remain across provider writes and
restart, and are available to the next engine turn without a fake execution.
See [session history](../session-history.md#transport-confirmed-outgoing-messages).

The one-level delegation and isolated fallback fixes from beta79 are retained.
Focused source tests cover exact delivery idempotency, the first outgoing
message before any model run, next-turn model context after restart, paginated
history, byte budgets and authorization boundaries. Live provider acceptance
and standalone product adoption remain separate qualification gates.
