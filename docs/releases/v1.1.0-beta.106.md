# Core 1.1.0 beta106

Fork from the transcript, and registry writes inside a host transaction.

- `SessionInspection.transcript` gives each finished visible prompt and answer
  a `message_id`, the durable row `fork_text` accepts, so a client can branch
  a conversation at the message it shows. Entry `id` values are unchanged.
- A `MemoryDB` borrowed with `from_connection` writes on the borrowed
  transaction. Since beta90, MCP source writes through
  `AutomationRepository.definition_store` opened a second writer that waited
  on the host's own `BEGIN IMMEDIATE` and failed with "database is locked".
