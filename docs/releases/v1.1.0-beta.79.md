# Core 1.1.0 beta 79

Delegation defaults to one worker level. The main run can still fan out to
parallel workers; an admitted worker cannot create a grandchild under the
default envelope. Hosted workers and native workers execute tools directly
without constructing implicit routing teams. Existing host-selected deeper
limits remain explicit opt-ins.

Catalog refresh creates a new fallback configuration rather than replacing
model objects in an initialized runner. This preserves the credentials and
models already selected by an in-flight turn. A remaining unresolved fallback
reference is resolved in a private snapshot; an unsupported reference cannot
mask the original provider error with an attribute error or hide a usable rung.

Qualification covers real Runtime admission and lineage, refusal before a
grandchild executor runs, parallel fan-out, cancellation of admitted children,
engine delegation through a registered proxy, catalog credential rotation,
and recovery or original-error preservation with unresolved fallback refs.
Provider and live channel acceptance is deployment-owned evidence.
