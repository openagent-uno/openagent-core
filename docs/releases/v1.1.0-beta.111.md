# Core 1.1.0 beta111

A paused goal stays in the prompt.

- A paused session goal still adds a `<session-goal>` block to every turn: the
  objective and the pause reason, as the standing context of the
  conversation, without the instruction to keep working. Before, only an
  active goal reached the prompt and no tool exposes it, so an agent whose
  goal had paused could not see its role or rules when the user wrote. An
  achieved goal still adds nothing.
