# Core beta143: provider-scoped shared subscription storage

Native subscription connections may explicitly partition their credential and
admission directories by provider. Hosts can mount one provider's canonical store
without exposing another provider's grants or starting a compatibility listener.
Existing flat stores retain their paths and behavior. Offline localization accepts
the fixed layout choice, preserves accounts and model references, and refuses
unreviewed or conflicting stores. Connection updates and image account deduplication
respect the storage identity. Public tests cover shared atomic rotation, isolated
layouts, invalid paths and connection settings. Installed and native-platform
qualification are required before release.
