# Core beta 135 — explicit account failover and deferred tool transcripts

Migrated multi-account subscriptions retain declared, same-model failover.
Each attempt uses the selected account's model settings, enabled state and
budget gate. Usage and the answer badge identify the account that handled the
request. No tool loop or partially emitted stream is replayed. Ordinary native
connections and stateless probes remain exact-account operations.

Host-supplied nonsecret protocol options preserve transport, model aliases,
deadlines, pacing and concurrency. A shared admission lane preserves one legacy
pool's limits after its rotating credentials are separated. Native subscriptions
never inherit an old API credential-pool override. Source license attribution
ships inside the subscription package.

`session_transcript.defer_tool_message_content` provides an opt-in projection
for already authorized tool cards. It defers only a linked invocation's text;
human/assistant content, unlinked results, attachment references and ordered UI
parts remain available. Hosts retain a separately authorized detail operation.
Storage and historical messages are unchanged.

Qualification is recorded after the final source regression suite. Provider,
installed-host and desktop acceptance are separate from synthetic protocol tests.
